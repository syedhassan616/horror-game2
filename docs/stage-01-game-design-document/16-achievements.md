# 16 — Achievements (78)

**Design rules:**
1. **No achievement is a spoiler.** Ending and secret achievements have oblique names
   and hidden descriptions, so the list is not a walkthrough.
2. **No achievement is gated on difficulty**, including CARRY ME mode (§13.6).
3. **No grind achievements.** Nothing asks for N of a thing you'd never otherwise do.
4. **Funny achievements are earned by playing oddly**, not by looking them up.
5. **Nine are genuinely hard.** Marked 🔒.

`H` = hidden until unlocked.

## 16.1 Notes on the Difficult Nine

🔒 achievements (25, 29, 32, 34, 39, 64, 74–78 core set) are hard because of **execution
or restraint**, never because of grinding. The hardest, #78, is a nine-region behavioural
condition the game never mentions — it is the achievement the community will spend the
longest decoding, and it is deliberately the one that rewards the game's central virtue:
*paying enough attention that you don't have to guess.*

## 16.2 Platform Mapping

- Steam: all 78, with hidden descriptions on the 21 marked `H`.
- Console (Switch/PS/Xbox, post-launch): identical set; platform trophy tiers map to
  Story (bronze) / Combat & Exploration (silver) / Endings & Superboss (gold) /
  #21 *The File Is Complete* (platinum).
- **No achievement requires an internet connection, a specific difficulty, or NG+ alone**
  — #63 and #20 span runs but chapter select (§13.4) makes them tractable.
