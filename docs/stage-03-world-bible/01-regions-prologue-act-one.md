# 01 — Regions I: The Unclaimed → Hushfell

---

## UNC · THE UNCLAIMED — 8 rooms

**Concept** A cold archive beneath the world. **Palette** Indigo / bone / one sodium amber.
**Forbidden colour** Green (appears once: the RESERVED stamp).
**Music** *Catalogue*, 62 BPM. **Weather** Dust in lamp-cones, breath fog.

| Room | Name | Class | Contents |
| --- | --- | --- | --- |
| UNC-01 | Aisle 900 | Chamber | Aven's drawer. S-001. No UI for 3s. |
| UNC-02 | Aisle 899 | Corridor | 22 readable drawers |
| UNC-03 | Aisle 898 | Chamber | 26 drawers incl. **Entry 12 (Ilsabet)**, **Entry 1441 (RESERVED)**. Absence #19. |
| UNC-04 | The Sorting Desk | Chamber | Osk. S-003, S-004, S-006, S-009. |
| UNC-05 | Aisle 901 | Corridor | 22 drawers |
| UNC-06 | Aisle 902, collapsed | **Arena** | Tutorial fight. Diagnosis card on the floor. |
| UNC-07 | The Shelving | Set piece | Osk's post-severance loop. Keyholeless door **#1**. |
| UNC-08 | The North Stair | Corridor | Exit. Parallax reveal. Look-back framing. |

**The seventy drawers** are distributed 22/26/22 across UNC-02/03/05. Each is a two-line
card (Stage 2 §04). Writing them is a **single-author task** — one voice, one sitting,
so the register holds.

**Keyholeless door response (UNC):** *"A door in a filing room. There is no lock and no
handle. Someone has written a number on the frame in pencil and then rubbed most of it
out."*

**Lighting:** one sodium practical per aisle, 40 units apart, so the player walks through
alternating pools of warm and cold. This is the game's first statement that light is
maintained by somebody.

**The Bell Count board (WYN-03)** is the game's most important prop. It is a slate with
90 chalk marks, updated by a boy with a ladder, and it is a **live readout of world
state** the player can consult at any time. It never explains itself.

**Stem map for *Ninety Bells*** (GDD §11.4):

| Bell Count | Stems active |
| --- | --- |
| 90–80 | Dulcimer, whistle, bodhrán, handbells, fiddle, drone (6) |
| 79–65 | −fiddle (5) |
| 64–50 | −bodhrán (4) |
| 49–35 | −dulcimer (3) |
| 34–20 | −handbells (2) |
| <20 | Whistle alone |

**Permanent.** No path re-enables a muted stem (GDD §11.6).

**Keyholeless door response (WYN):** *"Set into the tower's foundation, older than the
tower. The stone around it has been repointed four times and nobody has ever repointed
the door."*

## GRV · THE GRIEVING WOOD — 16 rooms

**Concept** Trees grown from buried keepsakes. **Palette** Nine greens + one impossible
pink at dusk. **Forbidden colour** Red (a bell-rope on a sapling).
**Music** *What We Planted*, 74 BPM. **Weather** Canopy wind in waves, synced to bar lines.

| Room | Name | Class | Contents |
| --- | --- | --- | --- |
| GRV-01 | The Eaves | Corridor | Light shafts introduced |
| GRV-02 | The Sexton's Barrow | Chamber | Quest 06. Absence #5. |
| GRV-03 | The First Planting | Set piece | Root Reading tutorial (the tin whistle tree) |
| GRV-04 | Deep Green | Corridor | Rootbound enemies |
| GRV-05 | The Twinned Root | Set piece | Quest 07 |
| GRV-06 | Moth's Clearing | Chamber | S-121, S-122. **F04, F17.** |
| GRV-07 | The Canopy Gaps | Set piece | P-GRV-1: light puzzle, grow a specific tree |
| GRV-08 | The Fresh Mound | Chamber | Absence #4. Odile's keepsake. |
| GRV-09 | Briarsome's Hollow | **Arena** | Optional boss B3. Arena shrinks permanently. |
| GRV-10 | The Buried Twice | Set piece | Quest 08 ★ |
| GRV-11 | Ivo & Nan's Plot | Chamber | Quest 09. The game's warmest scene. |
| GRV-12 | The Understory | Corridor | Mini-boss |
| GRV-13–16 | Trails | Corridor ×4 | 20 readable trees distributed; keyholeless door **#3** (GRV-14); 6 Keepsakes |

**Root Reading** is the region's verb and the game's environmental-storytelling engine.
Twenty trees; each read is 2–5 lines and a species. Species is *determined by what is
buried* — a rulebook exists (Stage 9) so players can predict what's under a tree from its
bark before digging. **Three players in playtest round 2 did this unprompted.**

**Keyholeless door response (GRV):** *"A door standing in open ground with no wall around
it. Something has grown up either side and left the frame alone."*

## HSH · HUSHFELL — 14 rooms

**Concept** A monastery where severance is offered, kindly, on request.
**Palette** White / pale blue / charcoal. **Forbidden colour** Warm yellow (kitchen window).
**Music** *A Kind Room*, 58 BPM. **Weather** Accumulating snow; persistent footprints
that fill in over ~90s.

| Room | Name | Class | Contents |
| --- | --- | --- | --- |
| HSH-01 | The Approach | Corridor | Absence #7 — the kitchen window from outside |
| HSH-02 | The Gate | Chamber | Brother Fen. Comic relief established immediately. |
| HSH-03 | The Kitchen | Chamber | **The one warm room.** 4 NPCs, bread, the kettle rota. |
| HSH-04 | The Waiting Room | Chamber | Candidate Ossa. S-135. |
| HSH-05 | The Register Hall | Set piece | 300 entries. Quest 13 ★. Absence #6. |
| HSH-06 | Annike's Office | Chamber | S-133, S-137 (**F05**), S-138 (Choice A) |
| HSH-07 | The Rite Room | Set piece | Plain. A table, two chairs, a window. |
| HSH-08 | The Cooling Cells | Chamber | Three days. Quest 10, 11. |
| HSH-09 | The Snowfield | **Arena** | Optional boss (Annike). Whiteout. |
| HSH-10 | The Clock Yard | Set piece | Mini-boss: The Three-Day Wait. 180s of not acting. |
| HSH-11 | The Bell | Chamber | Save/travel. Its tone is the flattest in the game. |
| HSH-12–14 | Cloisters | Corridor ×3 | Keyholeless door **#4** (HSH-13); 6 Keepsakes; Willing-family enemies |

**The Willing enemy family do not attack unless attacked.** In HSH-12–14 the player can
walk the entire region without a single fight. Roughly 30% do, and the game notices
(`flag:hushfell_peaceful`, read in three places).

**The Register Hall (HSH-05)** holds 300 entries as physically readable pages. Reading is
a *held* interaction — each takes ~4 seconds — so reading all 300 costs twenty real
minutes. Achievement #45 is one of the game's most-earned "hard" achievements because
players do it voluntarily, in silence, and report it as the best part of the region.

**Keyholeless door response (HSH):** *"In the cloister wall, and the snow in front of it
is undisturbed, and it has been snowing for four days."*
