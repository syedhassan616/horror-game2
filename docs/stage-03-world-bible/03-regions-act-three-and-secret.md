# 03 — Regions III: The Orrery → The Undersleep

---

## ORR · THE ORRERY — 15 rooms

**Concept** A shattered celestial machine. Island gravity is set by what it holds onto.
**Palette** Space-blue / brass / verdigris / starlight. **Forbidden colour** Skin tones
(the Untethered's hands). **Music** *Everything Holds Something*, 70 BPM, 7/8 gear tick.
**Weather** **None.** Vacuum-still, after seven regions of weather. Nobody comments.

| Room | Name | Class | Contents |
| --- | --- | --- | --- |
| ORR-01 | The Armature | Corridor | Attachment tutorial |
| ORR-02 | Vey's Observatory | Chamber | Quest 32. **F12 (shared vessel).** |
| ORR-03 | The Close Orbit | Set piece | P-ORR-1: re-parent gravity to roll a mass |
| ORR-04 | Apogee | **Arena** | Mini-boss |
| ORR-05 | The Drift | Corridor | Islands with no bond; momentum traversal |
| ORR-06 | The Untethered's Rock | Chamber | S-303. The persuasive case for severance. |
| ORR-07 | The Gear | Set piece | One enormous slow-turning gear as a moving platform |
| ORR-08 | The Long Chain | Set piece | P-ORR-2: tether islands in sequence |
| ORR-09 | The Empty Orbit | Chamber | **Absence #15.** Something orbits nothing. |
| ORR-10 | The Keeper's Three | **Arena** | Boss B7. Three islands, independent gravity. |
| ORR-11 | The Orrery Bell | Chamber | Save/travel. It rings in vacuum, which is wrong. |
| ORR-12–15 | Islands | Corridor ×4 | Keyholeless door **#9** (ORR-14) — the last one; 6 Keepsakes; Orbital enemies |

**Attachment** is the overworld tether. Re-parenting an island propagates through the
chain — a real constraint solver, not a scripted toggle, because players will build things
we didn't design and the physics must hold. This is the region's engineering risk and it
is scoped in Stage 10.

**ORR-14 holds the ninth door**, and the game has been showing the player doors since
minute fifteen. Finding all nine (Quest 35) is the superboss chain's first step and the
Journal has been logging them under *Questions* without being asked.

**Keyholeless door response (ORR):** *"On an island by itself, at the wrong angle to
everything. It is the ninth. You have started counting them."*

*(This is the only keyholeless-door response that acknowledges the player. It fires only
if the other eight are found first.)*

## REN · THE RENDERING — 5 rooms *(LEDGER-exclusive)*

**Concept** Industrial-scale intake. **Clean, well-lit, well-run, on shifts.**
**Palette** Institutional green / stainless / fluorescent. **Music** *The Ledger Line*,
early arrangement. **Weather** None. Air handling.

| Room | Name | Class | Contents |
| --- | --- | --- | --- |
| REN-01 | Reception | Chamber | Lanyards. A queue. A water cooler. |
| REN-02 | The Floor | Set piece | **S-342.** Aven can work a shift. Four minutes. Easy. |
| REN-03 | Break Room | Chamber | 4 NPCs on lunch. Nobody is a monster. |
| REN-04 | Records | Set piece | **S-343.** Annike's bulk petition. |
| REN-05 | The Line | **Arena** | Vellum, Final Audit |

**The design brief for this region:** it must be the most disturbing place in the game and
it must contain **nothing horrifying.** No screams, no restraints, no gore, no dark
corridors. It is an office that works well. If a build makes it look sinister, the build
is wrong.

## UND · THE UNDERSLEEP — 4 rooms *(secret; DRIFT-early)*

**Concept** A soft, wrong version of everywhere, populated by people **as Aven remembers
them.** **Palette** Oversaturated memory-colour, soft focus, no hard edges.
**Music** *As You Remember It* — every region theme detuned 12 cents, on music box.

| Room | Name | Class | Contents |
| --- | --- | --- | --- |
| UND-01 | The Soft Village | Chamber | Wyndmarrow, wrong. Everyone rings. Count is 90. |
| UND-02 | The Desk | Chamber | Osk, unsevered, mid-sentence, forever |
| UND-03 | The Long Room | Corridor | Every region, blended |
| UND-04 | The Version | **Arena** | Secret boss S1 |

**The only unambiguously warm place in the game, and it is a lie.** Nothing says so.

## KEP · THE KEEPING — 3 rooms *(secret)*

**Concept** Nine doors, one vault, 61,400 Wards, still warm. **The most beautiful room in
the game, hidden for six hours.** **Palette** Every region's palette at once, softly, like
light through a rose window. **Music** *Still Warm* — all four leitmotifs in counterpoint.

| Room | Name | Class | Contents |
| --- | --- | --- | --- |
| KEP-01 | The Vault Floor | Set piece | The plate: **61,400.** It is correct. |
| KEP-02 | The Doorway | **Arena** | **Superboss.** Absence #20 — a door open one inch, from the other side. |
| KEP-03 | Entry Two | Chamber | What comes through. Moth's first original sentence. |

**KEP-02 is one door-width wide and infinitely tall.** It never changes. Nine centuries of
not moving, expressed as level geometry.
